# 5axis3d.com

Website for **5axis3d.com** — five-axis conformal (non-planar) FDM 3D printing.

An exploration-stage prototype platform for research institutes, universities and advanced makers:

- 5-axis curved-surface / non-planar FDM printing
- Multi-axis motion control (POCENDER / PCD3D, RTCP) and curved-surface slicing
- Prototype machines, custom builds and joint development

## This repository

`index.html` is the complete current site as a single self-contained static file (styles and illustrations inlined). No build step is required.

Deploy: serve `index.html` as a static site (e.g. Cloudflare Pages — framework preset: none, build command: none, output directory: `/`).
